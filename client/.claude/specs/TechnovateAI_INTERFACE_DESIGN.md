# 1. Vision

**Brand Promise:** Innovate. Automate. Elevate.

Design goals:
- Build trust within 5 seconds.
- Clearly explain AI services.
- Maximize consultation bookings.
- Showcase technical expertise.
- Maintain enterprise-grade accessibility and performance.

# 7. Motion

Use motion only to guide attention.

Heavy animation:
- Hero
- AI Demo
- Storytelling sections

Light animation:
- Buttons
- Hover
- Cards
- Icons

Respect prefers-reduced-motion.
